# schmigui skills

Claude Code plugins by [schmigui](https://github.com/schmigui-dev).

## Install

```text
/plugin marketplace add schmigui-dev/skills
/plugin install <plugin>@schmigui
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [`parking-lot`](plugins/parking-lot) | Park ideas and questions mid-task, then come back later to discuss them, or edit, merge, renumber, and remove them. |
| [`mission-control`](plugins/mission-control) | Run agent work like a space mission. Brief and explore before, orchestrate a crew of agents, verify in layers, park questions instead of guessing, and make the go/no-go call before you ship. |
| [`same-page`](plugins/same-page) | Get code and business on the same page: a domain glossary built from any doc or code, drift checks, request translation, rule-to-test mapping, and safe renames. |
